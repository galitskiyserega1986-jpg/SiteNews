# SiteNews — «МосГород»

Статическая страница новостного портала: одна статья с шапкой, навигацией,
комментариями, сайдбаром и подвалом.

## Файлы

- `index.html` — статья (главная страница макета)
- `article.html` — та же статья (копия, для прямых ссылок на материал)
- `images/article.jpg` — исходное фото
- `images/hero.jpg` — кадрированная версия для обложки

Фото обложки встроено в HTML как `data:image/jpeg;base64`, поэтому страница
корректно отображается даже если развёрнут только один HTML-файл без папки
`images`.

## Адаптивность

Проверено на ширинах 320 / 360 / 390 / 430 / 600 / 768 / 900 / 1024 / 1440 / 1920 px:

- нет горизонтальной прокрутки и «съехавшей» вёрстки на мобильных;
- обложка масштабируется через `aspect-ratio` и ограничение по высоте;
- верхняя панель на телефоне показывает только город, погоду и пробки;
- меню разделов прокручивается по горизонтали (с затуханием у края);
- статьи, комментарии и сайдбар перестраиваются в одну колонку ≤900 px;
- на планшетах блоки сайдбара идут в две колонки;
- подвал: 3 → 2 → 1 колонка;
- иконки (поиск, уведомления, меню, соцсети, метаданные) — inline SVG,
  поэтому одинаково выглядят на Android, iOS и в десктопных браузерах.

## Локальный просмотр

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```
